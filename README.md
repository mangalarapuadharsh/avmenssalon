# Appointment Booking System

This is a full-stack appointment booking application for a barber shop.

## 🚀 How to Run the App

### 1. Start the Backend Server
The backend controls the database and login system. It **must be running** for the app to work.
- Double-click the **`start_server.bat`** file in this folder.
- A black window will open. **Keep this window open.**

### 2. Open the Frontend
- Open **`web/index.html`** in your browser.
- You can now login and book appointments.

## 📁 System Structure
- **Backend (Python)**: Runs on port 5000. Handles data.
- **Frontend (HTML/JS)**: Runs in your browser. Talks to the backend.

## ❓ Troubleshooting
- **"Server Offline"**: Make sure you ran `start_server.bat` and the black window is still open.
